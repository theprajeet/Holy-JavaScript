# Holy JavaScript

> The Only JavaScript Notes You Need

A collection of JavaScript concepts, from the fundamentals to more advanced topics, all kept in one place.

These notes are written with beginners in mind, so the concepts are explained step by step without assuming too much prior knowledge. They are also useful for revision and interview preparation, covering the core JavaScript topics you are expected to know as a frontend developer.

## How to Use

If you're new to JavaScript, start from the top and work through the notes in order. Each topic builds on concepts introduced earlier.

If you already have some experience with JavaScript, use the contents to jump directly to the topic you want to revise.

For interview preparation, go through the relevant notes first and then test yourself with questions instead of simply reading through the material again.

## Goal

Keep the important parts of JavaScript in one place — beginner-friendly enough to learn from, and focused enough to use for revision and interviews.
